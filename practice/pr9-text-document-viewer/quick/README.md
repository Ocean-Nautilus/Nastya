# Быстрый вариант: один скрипт, одна сцена

Минимальная рабочая версия текстового редактора — на случай, когда нужно
просто «чтобы работало». Полный вариант (11 скриптов, диалоги, автосохранение,
горячие клавиши) лежит в соседней папке `Assets/` и разобран в методичке.

## Что создать на сцене

1. Новая сцена → ПКМ в Hierarchy → **UI → Canvas** (объект EventSystem
   создастся сам — он обязателен, иначе кнопки не нажимаются).
2. На Canvas создайте элементы:

| Объект | Как создать | Настройка |
|---|---|---|
| `TextField` | UI → Input Field | Line Type: **Multi Line Newline**, Character Limit: 0, растянуть на весь экран, сверху оставить 80 px |
| `FileNameField` | UI → Input Field | Имя файла, вверху слева |
| `SearchField` | UI → Input Field | Строка поиска, вверху справа |
| `FileList` | UI → Dropdown | Список сохранённых документов |
| `StatusText` | UI → Text | Внизу экрана, статистика |
| 5 кнопок | UI → Button | «Новый», «Сохранить», «Открыть», «Найти» |

3. Создайте пустой объект **Editor** (ПКМ → Create Empty) и добавьте на него
   компонент `SimpleTextEditor`.
4. Перетащите в его поля: Text Field, File Name Field, Search Field,
   File List, Status Text.
5. Для каждой кнопки: Button → On Click() → «+» → перетащите объект **Editor** →
   выберите метод:

| Кнопка | Метод |
|---|---|
| Новый | `SimpleTextEditor.NewDocument` |
| Сохранить | `SimpleTextEditor.Save` |
| Открыть | `SimpleTextEditor.Open` |
| Найти | `SimpleTextEditor.Search` |

6. Нажмите **Play**.

## Проверка

Наберите текст → счётчики внизу меняются → введите имя файла → «Сохранить» →
«Новый» → выберите файл в списке → «Открыть» → текст вернулся.

Путь к папке с документами печатается в Console при запуске
(`Application.persistentDataPath/Documents`). Он работает и в готовой сборке,
в отличие от папки Assets, которая доступна только для чтения.
