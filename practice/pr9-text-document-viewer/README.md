# Практическая работа 9 — «Разработка модуля отображения текстовых документов»

В папке три варианта одной работы. Выбирайте по тому, что требуется сдать.

## 1. Unity 6.3 LTS + TextMeshPro — основной вариант

**Файл:** `Практическая работа 9 (Unity 6.3 LTS, TextMeshPro).docx` (19 страниц)
**Код:** `unity6-tmp/Assets/Scripts/`

Базовая инструкция под Unity 6.3 LTS и доработка, убирающая заглушки, сведены
в один файл: все листинги сразу в окончательном виде, переписывать их по ходу
работы не нужно. Шесть скриптов:

| Скрипт | Папка | Назначение |
|---|---|---|
| `TextDocument.cs` | Scripts/Data | Модель документа и статистика |
| `DocumentManager.cs` | Scripts/UI | Создание, открытие, сохранение, статистика, поиск |
| `SearchController.cs` | Scripts/UI | Строка поиска |
| `FileBrowserController.cs` | Scripts/UI | Список документов и выбор файла |
| `SaveAsController.cs` | Scripts/UI | Ввод имени файла при сохранении |
| `FormatController.cs` | Scripts/UI | Шрифт, размер и теги Rich Text |

Что исправлено по сравнению с первой версией инструкции:

- документы сохраняются в `Application.persistentDataPath` — папка со сборкой
  на многих платформах доступна только для чтения;
- `LoadDocument` принимает путь параметром, «Открыть» показывает список реальных
  файлов вместо одного захардкоженного `test_document.txt`;
- «Сохранить как» спрашивает имя файла и чистит его от запрещённых символов;
- подписка на `onValueChanged` в `Start` — без неё `OnTextChanged` не вызывался
  и статистика не обновлялась;
- выделение при поиске выставляется в корутине после `ActivateInputField`,
  иначе TMP сбрасывает его при получении фокуса;
- в `FormatController` дописаны подчёркивание, список шрифтов из
  `Resources/Fonts` и изменение размера шрифта.

### Готовый проект Unity

Папка `unity6-tmp/` — это полноценный проект Unity, а не просто набор скриптов:
`Assets/`, `Packages/manifest.json`, `ProjectSettings/`. Открывается через
Unity Hub → Add.

Сцена собирается скриптом `Assets/Scripts/Editor/TextEditorSceneBuilder.cs`:
он создаёт весь интерфейс теми же пунктами меню (GameObject → UI → …),
которыми пользуются вручную, расставляет элементы, добавляет компоненты и
прописывает события кнопок. Запускается сам при первом открытии проекта или
вручную: меню **Практика 9 → Собрать сцену**. После сборки сцену можно править
руками, а сам скрипт удалить.

## 2. Расширенный вариант на Legacy UI

**Файл:** `Практическая работа 9.docx` (57 страниц)
**Код:** `Assets/`

Полная методичка со скриншотами кода, 11 скриптов: диалоги, автосохранение,
список недавних документов, горячие клавиши, чек-лист тестирования,
контрольные вопросы, индивидуальные задания и приложения. Интерфейс на
`UnityEngine.UI` (Text, InputField, Dropdown) — в Unity 6 эти компоненты
помечены как Legacy.

## 3. Быстрый вариант

**Код и инструкция:** `quick/`

Один скрипт `SimpleTextEditor.cs` и сцена из десяти элементов — минимум,
чтобы «просто работало»: ввод, статистика, сохранение, открытие через
выпадающий список и поиск.

---

Все скрипты во всех трёх вариантах проверены компилятором C# на заглушках
Unity API — синтаксических ошибок нет. Интерфейс в первом варианте построен на
TextMeshPro, во втором и третьем — на `UnityEngine.UI`.
