# Практическая работа 9 — «Разработка модуля отображения текстовых документов»

Здесь лежит дописанный вариант практической работы 9 и исходный код всех
скриптов, которые в ней разбираются.

## Состав папки

| Файл / папка | Что это |
|---|---|
| `Практическая работа 9.docx` | Методичка целиком: части 1–10, контрольные вопросы, индивидуальные задания, требования к отчёту, критерии оценивания, вывод и приложения |
| `Assets/Scripts/Data/` | Модель документа и пути к файлам |
| `Assets/Scripts/UI/` | Контроллеры интерфейса |
| `Assets/Resources/test_document.txt` | Тестовый документ для проверки статистики, поиска и замены |

Части 1–5 документа — исходный текст работы, начиная с шага 5.4 — дописанная
часть. Все листинги в документе совпадают с файлами в этой папке.

## Скрипты

| Скрипт | Назначение |
|---|---|
| `Data/TextDocument.cs` | Модель документа: имя, путь, содержимое, даты, статистика (символы, слова, строки, абзацы, время чтения) |
| `Data/DocumentPaths.cs` | Папка документов через `Application.persistentDataPath`, проверка имён файлов |
| `UI/DocumentManager.cs` | Создание, открытие, сохранение, «Сохранить как», статистика, поиск, замена, отслеживание несохранённых изменений |
| `UI/SearchController.cs` | Панель поиска и замены: «Найти», «Найти далее», «Заменить», «Заменить все» |
| `UI/FormatController.cs` | Выбор шрифта, размер шрифта, маркеры форматирования |
| `UI/FileBrowserController.cs` | Список документов и выбор файла |
| `UI/SaveDialogController.cs` | Диалог ввода имени файла |
| `UI/ConfirmDialog.cs` | Вопрос о несохранённых изменениях |
| `UI/AutoSaveController.cs` | Автосохранение по таймеру |
| `UI/RecentFilesManager.cs` | Список недавно открытых документов в `PlayerPrefs` |
| `UI/HotkeyController.cs` | Горячие клавиши Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+F, Ctrl+Q |

## Как собрать проект в Unity

1. Создайте проект «TextDocumentViewer» (шаблон 2D или 3D — не важно).
2. Скопируйте папку `Assets` из этой папки в проект поверх существующей.
3. Соберите сцену по частям 2, 5, 6, 7 и 8 документа и заполните поля
   компонентов в инспекторе.
4. Шрифты (`.ttf`) положите в `Assets/Resources/Fonts` — иначе выпадающий
   список шрифтов останется пустым.

Интерфейс построен на компонентах `UnityEngine.UI` (Text, InputField,
Dropdown, Toggle), без TextMeshPro. Код совместим с Unity 2019.1 и новее.
Если в Project Settings → Player → Active Input Handling выбран только
«Input System Package (New)», переключите настройку на «Both» — иначе
`HotkeyController` не скомпилируется.
