# TextDocumentViewer — практическая работа 9

Проект для Unity 6.3 LTS (TextMeshPro). Текстовый редактор: создание,
сохранение, открытие документов, статистика, поиск с подсветкой и
форматирование.

## Как запустить

1. Распакуйте архив.
2. Unity Hub → Add → выберите папку `TextDocumentViewer` → откройте проект.
3. Если Unity предложит импортировать ресурсы TextMeshPro — нажмите
   **Import TMP Essentials**. Без них TMP-элементы не отображаются.
4. Сцена `Assets/Scenes/TextEditorScene.unity` собирается автоматически при
   первом открытии проекта. Если этого не произошло (например, ресурсы TMP
   импортировали позже) — выберите в верхнем меню **Практика 9 → Собрать сцену**.
5. Откройте сцену и нажмите **Play**.

## Что проверить

| Действие | Ожидаемый результат |
|---|---|
| Набрать текст | Внизу меняются счётчики символов, слов и строк |
| «Сохранить как» → имя → «Сохранить» | В Console путь к файлу, в заголовке пропадает звёздочка |
| «Новый» → «Открыть» | Появляется список сохранённых документов |
| Выбрать файл в списке | Текст загружается, панель закрывается |
| Ввести слово → «Поиск» | Совпадение подсвечивается прямо в тексте |
| Выделить слово → Ж / К / Ч | Текст становится жирным, наклонным, подчёркнутым |

Документы сохраняются в `Application.persistentDataPath/Documents` — полный
путь печатается в Console при запуске сцены.

## Структура

```
Assets/
├── Scenes/TextEditorScene.unity      — сцена (создаётся сборщиком)
├── Prefabs/FileButtonTemplate.prefab — кнопка файла в списке
├── Resources/Fonts/                  — сюда кладут TMP Font Asset
└── Scripts/
    ├── Data/TextDocument.cs          — модель документа и статистика
    ├── UI/DocumentManager.cs         — создание, открытие, сохранение, поиск
    ├── UI/SearchController.cs        — строка поиска
    ├── UI/FileBrowserController.cs   — список документов
    ├── UI/SaveAsController.cs        — ввод имени файла
    ├── UI/FormatController.cs        — шрифт, размер, теги Rich Text
    └── Editor/TextEditorSceneBuilder.cs — сборка сцены (только редактор)
```

`TextEditorSceneBuilder` создаёт интерфейс теми же пунктами меню
(GameObject → UI → …), которыми пользуются вручную, расставляет элементы,
добавляет компоненты и прописывает события кнопок. После сборки сцену можно
свободно править руками — скрипт больше не нужен, его можно удалить.

## Если что-то не так

- **Меню «Практика 9» нет** — Unity ещё компилирует скрипты, подождите или
  проверьте Console на ошибки компиляции.
- **Вместо текста пустые прямоугольники** — не импортированы TMP Essentials
  (Window → TextMeshPro → Import TMP Essential Resources), после импорта
  соберите сцену заново.
- **Ошибка разрешения пакетов** — удалите `Packages/manifest.json`, Unity
  создаст его заново под вашу версию редактора.
- **Собрать сцену заново** — удалите `Assets/Scenes/TextEditorScene.unity` и
  выберите «Практика 9 → Собрать сцену».
