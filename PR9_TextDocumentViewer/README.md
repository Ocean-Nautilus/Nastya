# PR9 — TextDocumentViewer

Практическая работа 9 «Разработка модуля отображения текстовых документов» (Unity 6000.6, TextMeshPro).

Сцена: `Assets/Scenes/TextEditorScene.unity`.

## Возможности

- **Новый / Открыть / Сохранить / Сохранить как** — `DocumentManager`. В редакторе документы лежат в `Assets/Documents` (есть `Пример.txt`), в билде — в `persistentDataPath/Documents`.
- **Заголовок** показывает имя файла и `*`, если есть несохранённые изменения.
- **Строка статуса** — символы, слова, строки (теги форматирования не считаются) и сообщения («Сохранено», «Найдено 2 из 5», «не найдено»).
- **Поиск** — кнопка «Поиск» или Enter в поле поиска. Регистр не учитывается, повторное нажатие переходит к следующему совпадению (после последнего — снова к первому), найденный фрагмент выделяется.
- **Ж / К / Ч** — жирный, курсив, подчёркивание выделенного фрагмента (теги Rich Text `<b>`, `<i>`, `<u>`). Повторное нажатие снимает стиль.
- **Размер** — введите число (8–72) и нажмите Enter: с выделением меняется размер только фрагмента (`<size=N>`), без выделения — размер всего текста.
- **Шрифт** — выпадающий список: Liberation Sans (по умолчанию) и все шрифты из `Assets/Resources/Fonts` (Liberation Serif, Liberation Mono, DejaVu Sans, DejaVu Serif — все с кириллицей). TMP-ассеты для них создаются автоматически при запуске, чтобы добавить свой шрифт, достаточно положить `.ttf` в эту папку.
