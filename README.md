# Дневник — мобильное приложение для личных записей с настроением

Учебный проект по **МДК 01.03 «Разработка мобильных приложений»**.
Тема №16 из технического задания — *«Дневник»: личные заметки с настроением*.

> **Статус:** разработка завершена. Все 12 недель плана пройдены — см.
> [docs/02-development-plan.md](docs/02-development-plan.md). Каждая неделя
> закрыта отдельным коммитом в этот репозиторий.

## О приложении

«Дневник» — Android-приложение, в котором пользователь ведёт личные записи,
отмечает настроение дня, распределяет записи по категориям и тегам, ищет их
по тексту и смотрит статистику своего эмоционального состояния.

### Изюминка проекта

1. **Полнотекстовый поиск** по заголовку и содержимому записей на базе
   виртуальной таблицы SQLite FTS4 — мгновенный поиск с подсветкой совпадений,
   а не медленный `LIKE '%...%'`.
2. **Экспорт дневника в PDF** — все записи выгружаются в оформленный
   PDF-документ, который можно сохранить или отправить.

## Технологический стек

| Слой | Технология |
|------|-----------|
| Язык | Kotlin |
| Платформа | Android (minSdk 24, targetSdk 34) |
| Архитектура | MVVM (ViewModel + StateFlow + Repository) |
| База данных | SQLite через Room (+ виртуальная таблица FTS4) |
| Асинхронность | Kotlin Coroutines + Flow |
| Интерфейс | View + ViewBinding, Material Design 3 |
| Навигация | Navigation Component + BottomNavigationView |
| Графики | MPAndroidChart |
| Настройки | Jetpack DataStore Preferences |
| Экспорт | android.graphics.pdf.PdfDocument |

## Сборка проекта

```bash
git clone https://github.com/Ocean-Nautilus/Nastya.git
cd Nastya
./gradlew assembleDebug
```

Готовый APK окажется в `app/build/outputs/apk/debug/`.
Требуется JDK 17 и Android SDK 34.

## Проверка проекта
