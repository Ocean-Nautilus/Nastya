О приложении «Дневник»

Это удобное мобильное приложение для Android, которое помогает вести личные записи и следить за своим эмоциональным состоянием.
Главные функции:

    Личные заметки: создание, редактирование и удаление записей.

    Трекер настроения: отметка эмоционального фона для каждого дня.

    Категории и теги: удобная сортировка и фильтрация записей.

    Наглядная статистика: графики активности и распределения настроения.

    Настройки: выбор темы оформления и параметров отображения.

Особенности проекта:

    Быстрый поиск (FTS4): мгновенный поиск по заголовкам и текстам записей с подсветкой результатов.

    Экспорт в PDF: выгрузка всех записей в аккуратный документ для сохранения или отправки.
