# Лекция 4. Индексы — практическая работа

База данных: **Archive_Muzi** (учёт аренды музыкального оборудования), MS SQL Server / SSMS.

## Файлы

| Файл | Назначение |
|---|---|
| `01_наполнение_данными.sql` | Пункт 1: наполнение базы (Clients 2000, Equipment 500, Rentals 5000, RentalItems 8000, Payments 6000, Maintenance 1000) |
| `02_запросы_и_индексы.sql` | Пункты 2–7: три поисковых запроса, создание индексов, повторные запросы, составной индекс |
| `Индексы.docx` | Отчёт по работе с местами под скриншоты |

## Порядок выполнения в SSMS

1. Открыть `01_наполнение_данными.sql`, выполнить целиком (F5). В конце скрипт покажет количество строк в каждой таблице — сделать скриншот.
2. Открыть `02_запросы_и_индексы.sql`.
3. Включить `Query → Include Actual Execution Plan` (**Ctrl + M**).
4. Выполнять блоки по очереди сверху вниз (выделить блок → F5), не весь файл сразу.
5. После каждого запроса сохранять:
   - вкладку **Execution plan** (скриншот),
   - вкладку **Messages** — там выводятся `logical reads` (`SET STATISTICS IO ON`).
6. Числа из Messages вписать в таблицы отчёта `Индексы.docx` вместо примерных значений и вставить скриншоты на отведённые места.

## Что показывается в работе

- Запрос 1 — `Clients` по `phone` → индекс `IX_Clients_Phone`
- Запрос 2 — `Equipment` по `brand` → индекс `IX_Equipment_Brand` (покрывающий, с `INCLUDE`)
- Запрос 3 — `Payments` по диапазону дат → индекс `IX_Payments_PaymentDate`
- Запрос с двумя условиями — `Rentals` по `client_id` + `start_date` → составной индекс `IX_Rentals_Client_StartDate`
  (порядок столбцов: сначала равенство `=`, затем диапазон `>=`)
